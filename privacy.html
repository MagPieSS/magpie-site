Magpie

Privacy policy

Last updated 12 November 2026.

Magpie is a desktop assistant that runs on the user's own Windows computer. This policy explains what happens to data, including data from Google accounts the user connects.

Data from Google

When the user connects a Google account, Magpie can access only the Google apps the user switches on: Google Drive, Docs, Sheets, Calendar and Gmail. It uses that access only to do what the user asks in a chat, such as finding a file, reading a document or an email, adding a calendar event, or sending an email. Every change in Google is shown to the user and waits for their confirmation.

Magpie does not sell Google data, does not use it for advertising, does not use it to train AI models, and does not transfer it to the developer or to any third party. People do not read it, except the user.

Magpie's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where data is kept

  • Chats, notes and the activity log are stored in a database on the user's computer.
  • The Google sign-in (refresh token) is encrypted with the user's Windows account and stored on that computer. Short-lived access tokens are kept only in memory.
  • Magpie has no server of its own and collects no analytics or telemetry.

What leaves the computer

  • To Google: the requests needed to do what the user asked, such as search words, the id of a file being read, or a change the user confirmed.
  • To an AI provider, only if the user chooses one: Magpie's AI model normally runs locally. If the user picks an optional cloud model (Google Gemini or a model through OpenRouter) for a chat, the content of that chat, including any Google data read during it, is sent to that provider under its own terms.
  • Web access, only if the user turns it on: search words and page addresses go to the search service and the sites being read.

Removing access and data

The user can disconnect a Google account at any time in Magpie under Settings, then Google. This deletes the stored sign-in and asks Google to revoke it. Access can also be removed at myaccount.google.com/permissions. Uninstalling Magpie and deleting its data folder removes everything it stored.
