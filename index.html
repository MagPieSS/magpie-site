Magpie

A personal desktop assistant for Windows that runs its AI model locally on the user's own computer.

What it does

Magpie is a chat assistant that can work with files in folders the user picks, keep tasks and notes, and, if the user connects a Google account, work in that account's Google Drive, Docs, Sheets, Calendar and Gmail.

How it uses Google

  • The user signs in through Google's own consent page in their browser. Magpie never sees the Google password.
  • Magpie only acts in Google when the user asks it to in a chat.
  • It reads freely, but every change (editing a document, writing a spreadsheet, adding an event, sending or drafting an email, sharing or trashing a file) is shown to the user in a confirmation dialog first, and nothing happens if they decline.
  • Google data is processed on the user's own computer and is not sent to the developer or to anyone else.

Magpie is a personal project used by its developer and is not offered to the public.
